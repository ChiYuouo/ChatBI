# 项目文档

## 总规划

[企业改造总规划](enterprise-transformation-plan.md) 记录产品定位、整体架构、模块职责、阶段顺序及总体完成标准。阶段实施记录通过链接进入，不在总规划里持续累积。

## 阶段文档

| 阶段 | 当前状态 | 文档 |
|---|---|---|
| 第一阶段：统一查询执行与安全边界 | 当前约定的MVP范围已完成；267项回归、独立初始化及真实前端/模型冒烟通过 | [第一阶段](stages/phase-1-query-execution.md) |

后续阶段开始实施时，在 `stages/` 下建立对应的独立文档，并更新本目录和总规划中的入口。同一阶段的后续改动继续写在同一份阶段文档中，不为每次提交另建文档。

## 记录约定

每份阶段文档包含：

- 阶段目标、任务范围和验收条件。
- 已完成任务、对应改动及代码提交。
- 验证方式、真实结果和未验证范围。
- 当前限制、未完成任务和下一组工作。

明确区分“某组任务已完成”和“整个阶段已完成”。只有阶段验收条件全部满足，才标记阶段完成；总规划只同步简要状态与阶段文档链接。
