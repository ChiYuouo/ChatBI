## 本阶段范围与用户确认

- 保留现有 Python/FastAPI 主链路，将模型生成与受控 SQL 执行分开；普通查询、SSE、Agent 子步骤和修复重试共用执行入口。
- 完善可信身份、表/字段权限、区域过滤、只读 SQL、执行预算、连接池和只读数据库账户。
- 沿用已有指标知识和 Schema Linking，修正具体口径冲突；运行按当前日期，复用用户已经更新到最近几个月的数据。
- 补齐索引首次初始化、持久化、版本识别、干净构建及健康就绪，完成当前环境的真实查询验证。
- **按用户要求，不保留绑定固定表/字段的汇率执行前检查。** 人民币换算保留为提示词和模板约定；成本快照、数量单位扩表也不作为本阶段强制任务。

完成本阶段不代表已经支持任意企业 Schema、租户隔离或完整会计分析。这些能力按后续阶段建设。

## 已完成任务

| 任务 | 主要位置 | 最终行为 |
|---|---|---|
| 可信身份 | `core/security.py`、`api/dependencies.py`、查询/分析服务 | 从验签 token 与当前用户记录取得身份；缺身份、pending、销售缺区域时拒绝，公开健康接口不授予分析身份 |
| 统一执行入口与独立结果 | `contracts/execution.py`、`execution/query_executor.py`、`infrastructure/database.py` | 同步、流式、子步骤及修复都经过同一安全入口；兼容二元组 execute；返回实际 SQL、结果、耗时，不使用共享 last_query_info |
| AST 安全与区域范围 | `execution/sql_policy.py`、`core/security.py` | 校验五张业务表、字段来源与函数，展开普通星号；客户归属区域过滤每个订单/客户基础表，OR、别名、CTE/UNION不能绕过 |
| 执行预算与连接池 | `execution/budget.py`、`execution/budgeted_llm.py`、数据库与分析服务 | 请求总时间、SQL次数与累计字节共享；单条 SQL 行数/字节/服务端时间受限，逐行读取，超限失败且销毁未读完连接；池容量、等待及关闭线程安全 |
| 只读账户与部署配置 | `docker/mysql/init/02-reader.sh`、Compose、依赖配置 | reader仅有五张业务表SELECT；root只用于初始化/授权；管理密码不传后端，MySQL8 RSA认证依赖完整 |
| 业务口径与多轮顺序 | `prompt_builder.py`、`indicators_full.json`、字段说明、查询服务 | 先改写再检索；收入统一人民币，CNY直接计入，外币按订单日期/币种换汇；毛利减产品当前人民币成本估算；利润明确为简化经营利润 |
| 分析范围传递 | `analysis/agent_planner.py`、`analysis/query_decomposer.py` | 每个子查询携带整体问题及范围约束；依赖结果附实际SQL。子任务按业务指标拆分，避免将过滤/关联/汇总拆成多步后丢失范围；保持自定义执行器首行兼容 |
| 统一索引准备 | `retrieval/index_manager.py`、`tools/init_indexes.py`、三个检索模块 | 表/字段/指标共享准备流程；按启用功能构建。定义与Embedding模型/地址摘要识别过期，检查实际ID集合及维度；原子发布版本，初始化并发加锁；API失败不先清空旧数据 |
| 首次启动与持久化 | Dockerfile、Compose、`.dockerignore` | 镜像不复制本机索引、环境秘密或本地账户/会话库；index-init先准备索引，再启动后端；向量索引使用独立持久卷 |
| 健康与就绪 | `api/routes.py`、前端健康提示 | /health只读检查数据库及启用索引，未就绪返回503；/live只检查进程。查询缺索引在模型调用前明确失败，多步不继续生成完整报告；前端区分数据库异常、检索未就绪和服务离线 |
| 清理 | 指标文件、表元数据、索引构建器及文档 | 移除无运行引用的旧indicators.json、四张不对应业务库的测试干扰表；合并重复构建逻辑，字段检索返回当前定义；清理过期阶段待办 |

销售当前可查订单数量、销量和授权区域的非金额明细；金额、成本、费用仍拒绝，受审的区域财务指标属于后续治理。分析功能也沿用显式开关，不再因遗漏参数而默认开启检索。

## 已确认的边界与后续阶段

- 安全策略、Schema、关联图和指标仍属于当前制造业五表模型；多数据源连接可切换，不代表元数据或权限已按企业隔离。租户/成员/数据源治理按后续阶段实施。
- 后端**不主动拦截缺失汇率**；LEFT JOIN产生的NULL可能被SQL聚合忽略。现有缺失键为2026-08-13/USD与2026-08-05/EUR，未猜测或补录。提示词约定不能替代完整财务数据治理。
- 成本按产品当前值估算，不宣称历史实际成本；销量不同单位未做统一换算；没有费用分摊时不提供产品线/区域经营利润。旧评测参考口径需在下一次独立评测前整理。
- 原问题范围传递能减少拆解遗漏，但不是任意模型SQL业务语义的确定性证明；完整指标治理、证据与报告绑定属于后续工作。
- 窗口函数、相关子查询、递归CTE、跨库、写入、系统表及未批准函数暂不支持。
- 预算在阶段边界和网络调用处收紧，本地同步计算不能立即强制中断；结果字节不包含SQL、报告和SSE封装。持久任务、取消、恢复与权威状态按后续阶段建设。
- 索引版本与持久化已完成，尚未实现按租户/数据源发布、在线切换与回滚；当前重建过程中保持“未就绪”，不冒称无停机更新。
